# 百層週報

週1回ターンが進む、読者参加型の百層の塔ゲーム。10階ごとの守護者を、みんなの与ダメージを合算して倒し、百層の主を倒した人が塔主になる。

## 構成(予定)

| 役割 | 場所 |
|---|---|
| 画面(静的なHTML/JavaScript) | このリポジトリ → Cloudflare Pagesで公開 |
| データ・ログイン・判定ルール | Supabase(プロジェクト `hyakusou`) |
| ターン進行・ディレクター | Claude(最初は手動で依頼、のちに自動化) |

## フォルダ

- `prototype/` 一人用のテスト版(判定も画面も1ファイル)。バランス調整と遊び心地の確認用。Supabaseにはつながっていない。

## 方針

- 判定のルール(敵の強さ、ドロップ表、職業の数値など)は、Supabase側の非公開領域に置く。このリポジトリには入れない。
- 秘密のキー(サービスロールキー、APIキー)は、このリポジトリに絶対に入れない。画面に入れてよいのは、SupabaseのURLと公開用のanonキーだけ。
- 次の話の下書きや没にした設定は、このリポジトリに置かない。

## ゲームの流れ

1. 毎週、装備・職業・探索の方針を選ぶ。
2. ターンが進み、探索が自動で解決される。
3. 結果の報告書(戦利品、レベルアップ、守護者の進み具合、突発イベント)を読む。
4. 第10層まではチュートリアル。第11層から属性の敵と職業が解禁される。

## 画面 (docs/)
- `docs/index.html` … Supabaseにつながる本番用の画面(HTML/JSのみ、ビルド不要)。テスト中はGitHub Pagesで公開(Settings → Pages → Branch: main / docs)。本番はCloudflare Pagesの出力ディレクトリに `docs` を指定する。
- `prototype/index.html` … 一人用の試作版(参考用)。

## 現在の作り(試しの塔 / 2026-11 作り直し)
- 百層の塔の前に、1人用の「試しの塔」(10階建て・10階に守護者)を作った。紙芝居(導入ストーリー)つき。
- ルールはシンプルに: 武器7種・盾7種(トルネコ風)、薬草、冒険→拾う→売る→買う。職業・属性・強化は無し。
- 判定はすべてSupabase側(`engine.trial_explore` など)。画面は `docs/index.html`。
- 以前の共有の塔(合算ダメージ・ターン処理)は保留中。DBには残しているが、今の画面からは使っていない。


## 冒険(対話式)
冒険は1階=3部屋。部屋ごとに2つの道(戦闘/強敵/宝箱/泉/怪しい扉)から選び、戦闘では敵の「次の行動」を見て 攻撃・強打・防御・薬草・逃げる・おまかせ を選ぶ。
踊り場で「下りる/帰る」を選び、2・4・6・8階では加護を1つ授かる。倒れると、その冒険で拾った物とお金は失う。
装備には+0〜+3の強化値があり、売値にも反映される。サーバー側は `engine.run_cmd`、公開口は `public.t_run`。
