# 百層日報

平日に毎日1回ターンが進む、読者参加型の百層の塔ゲーム。10階ごとの守護者を、みんなの与ダメージを合算して倒し、百層の主を倒した人が塔主になる。

## 構成(予定)

| 役割 | 場所 |
|---|---|
| 画面(静的なHTML/JavaScript) | このリポジトリ → Cloudflare Pagesで公開 |
| データ・ログイン・判定ルール | Supabase(プロジェクト `hyakusou`) |
| ターン進行・ディレクター | Claude(最初は手動で依頼、のちに自動化) |

## フォルダ

- `prototype/` 一人用のテスト版(判定も画面も1ファイル)。バランス調整と遊び心地の確認用。Supabaseにはつながっていない。

## 方針

- 判定のルール(敵の強さ、ドロップ表、職業の数値など)は、Supabase側の非公開領域に置く。このリポジトリには入れない。
- 秘密のキー(サービスロールキー、APIキー)は、このリポジトリに絶対に入れない。画面に入れてよいのは、SupabaseのURLと公開用のanonキーだけ。
- 次の話の下書きや没にした設定は、このリポジトリに置かない。

## ゲームの流れ

1. 毎週、装備・職業・探索の方針を選ぶ。
2. ターンが進み、探索が自動で解決される。
3. 結果の報告書(戦利品、レベルアップ、守護者の進み具合、突発イベント)を読む。
4. 第10層まではチュートリアル。第11層から属性の敵と職業が解禁される。

## 画面 (docs/)
- `docs/index.html` … Supabaseにつながる本番用の画面(HTML/JSのみ、ビルド不要)。テスト中はGitHub Pagesで公開(Settings → Pages → Branch: main / docs)。本番はCloudflare Pagesの出力ディレクトリに `docs` を指定する。
- `prototype/index.html` … 一人用の試作版(参考用)。

## 現在の作り(試しの塔 / 2026-11 作り直し)
- 百層の塔の前に、1人用の「試しの塔」(10階建て・10階に守護者)を作った。紙芝居(導入ストーリー)つき。
- ルールはシンプルに: 武器7種・盾7種(トルネコ風)、薬草、冒険→拾う→売る→買う。職業・属性・強化は無し。

## 遊び方(定期更新)
- ターンは平日(月〜金)の12:00に1回。プレイヤーは「作戦」を2択で決めておく:階を指定する。「最前線に挑む」(到達階に挑む。守護者の階では守護者戦。到達階が上がっても追従する)か、突破済みの階を指定して周回する(稼ぎ場を狙い撃ち)。決めなかった日は前回と同じ作戦。荷物(薬草5個まで)は自動。
- ターン処理(`engine.season_turn()`)で全員の冒険が自動で解決され、日報(`turns`: 見出し・最前線・ピックアップ候補・`news`)と個人の結果(`logs`)が出る。公開されるのは到達階だけ。毎ターン、Claudeが `turns.body.news`(最前線ニュース)と `pickups`(うまい行動をした人)を書き換える。自動実行はまだ無く、`select engine.season_turn()` を手動で回す。
- 10階ごとの守護者は、全員のダメージを合算して倒す。倒した人に特別な装備、貢献した人にお金。
- 人が少ない間は、ボット冒険者が同じ塔を登る。登録直後の最初の1回だけは、待たずにすぐ結果が出る。
- 道具屋で買えるのは一般的な装備だけ(木の棒・銅の剣・鉄の斧、皮・青銅・うろこの盾、薬草)。竜殺しの槍や紅蓮の剣などの強い装備は、ドロップ(階ごとに出る装備が変わる)と守護者の報酬でしか手に入らない。
- 稼ぎ場: 3・5・8・12・16・24階には強い装備が低確率で出る。突破済みの稼ぎ場の階を指定して周回する。外すたびに確率が上がる(天井)。設定は `engine.rules`(key=season の farm)と `public.season.farm`、連続ハズレ数は `players.pity`。
- 初期は30階まで。最上階の守護者を倒した人が塔主になる。
- 冒険の解決エンジンは `engine.run_cmd`、自動操縦は `engine.auto_dive`、守護者戦は `engine.guardian_fight`。
